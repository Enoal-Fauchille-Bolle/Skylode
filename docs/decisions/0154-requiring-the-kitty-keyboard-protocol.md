# 0154 — Requiring the kitty keyboard protocol

**Status:** rejected
**Tags:** ui
**Supersedes:** —
**Superseded by:** —

## Decision

Requiring the kitty keyboard protocol

## Why

It would exclude every VTE terminal — **Ptyxis, Fedora's default and this project's own
dev terminal** — plus gnome-terminal, Console, Tilix, Terminator, Guake, Terminal.app,
xterm and Konsole, for a game whose pitch is a single cross-platform offline binary. VTE
support is a merge request still in review.
