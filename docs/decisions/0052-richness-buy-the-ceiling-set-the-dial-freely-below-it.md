# 0052 — Richness: buy the ceiling, set the dial freely below it

**Status:** accepted
**Amended:** once
**Tags:** mines
**Supersedes:** —

## Decision

Richness: buy the ceiling, set the dial freely below it

## Why

The compression rule again, for the same reason: one free action always puts a run in
the shape the current goal wants, so a purchase can slow a run down but never strand it.

## Amendments

### a maxed dial follows the ceiling it was already at

Replaced: every purchase left the dial where it stood.

A dial that was already *at* the ceiling now follows the purchase onto the new one; a
dial parked below it is untouched. The condition is the whole of it. A player holding
the dial at the top has already answered "where do you want it", so charging them a
keypress with one possible answer after every buy is friction, not freedom — and a
ceiling the dial never reaches is ore spent on nothing. A dial held *low*, by contrast,
is a real position: on the three substitution mines it buys a faster grid, and the
Netherite Efficiency recipe has an *optimum* share rather than a maximal one
([0022](0022-netherite-efficiency-6-15-is-paid-in-obsidian-crying.md)), so overruling it
would break exactly the freedom this record is about.

Evidence that the rule was already needed: the two balance harnesses had each been
pinning the dial by hand after every purchase, which is the same rule written twice in
the only place that could not benefit from it.
