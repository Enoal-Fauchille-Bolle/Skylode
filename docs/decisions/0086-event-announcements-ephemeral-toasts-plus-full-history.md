## Decision

Event announcements: ephemeral toasts plus full history in Stats

## Why

No screen owned announcements, yet six mechanics need one — level-up rewards, Excavator
procs, Nuke, batch reset, offline credit, and the `compress first` / `go mine more`
refusal MECHANICS explicitly demands the UI tell apart. Toasts cost **zero permanent
layout rows**, which decides it: the Mine screen has only 7 spare rows at 80×24.
