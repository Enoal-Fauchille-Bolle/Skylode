## Decision

Language: English, no i18n

## Why

Docs, commits, code and rustdoc are already English, materials are Minecraft's English
names, and crates.io publication is planned. A translation layer would desynchronise the
UI from the core (`Material::IronOre` shown as "Minerai de fer") for a need that does
not exist.
