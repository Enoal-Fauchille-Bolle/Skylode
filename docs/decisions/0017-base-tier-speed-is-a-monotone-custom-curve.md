# 0017 — base_tier speed is a monotone custom curve

**Status:** accepted
**Tags:** pickaxe
**Supersedes:** —
**Superseded by:** —

## Decision

`base_tier` speed is a monotone custom curve

## Why

Minecraft's tool speeds are non-monotone (gold beats diamond); the 1:1 principle is kept
only for hardness. See [MECHANICS.md](../MECHANICS.md#pickaxe-progression).
